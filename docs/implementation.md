# Entre Nós

Portal editorial estático em português, gerado com Python sem dependências, com HTML semântico, CSS responsivo e JavaScript progressivo.

1. Criar dados editoriais, templates reutilizáveis e páginas estáticas de artigos e categorias.
2. Implementar identidade visual Midnight/Pearl/Ocean, navegação móvel, busca e compartilhamento.
3. Implementar curadoria e formulários com validação, sem simular integração externa.
4. Gerar metadados, sitemap e robots; verificar rotas, HTML, JavaScript e comportamento no navegador quando disponível.

Nome provisório aprovado: Entre Nós. Conteúdos e imagens são demonstrativos; não atribuir experiências pessoais à criadora. Nenhum link afiliado, domínio, perfil social ou serviço de e-mail foi fornecido. Esses campos ficarão explicitamente pendentes. Publicação e processamento real de dados dependem dessas configurações.
